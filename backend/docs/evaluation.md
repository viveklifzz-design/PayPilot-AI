# PayPilot AI — Evaluation Benchmark Documentation

## 1. Executive Summary & Purpose
The PayPilot AI Evaluation Engine provides a reproducible, seed-based batch benchmark evaluation framework to assess revenue-recovery decision quality, policy safety enforcement, and simulated recovery yields across configurable synthetic datasets (100, 500, 1,000, 2,000 failure cases).

> [!IMPORTANT]
> **Data Isolation Notice**: Evaluation results are strictly synthetic and do not represent real customer revenue or execute live Razorpay payments. Live Razorpay Test Mode transactions remain strictly isolated from synthetic evaluation data.

---

## 2. Dataset Schema
Every synthetic failure case generated by `SyntheticDatasetGenerator` includes:
- `case_id`: Unique identifier (e.g. `eval_case_42_0001`)
- `payment_id`: Transaction reference
- `customer_id`: Anonymized customer identifier
- `amount`: Failed transaction amount in INR (range ₹499 to ₹75,000)
- `currency`: `INR`
- `payment_method`: `upi`, `card`, or `netbanking`
- `failure_reason`: Realistic payment failure code (`BAD_REQUEST_PAYMENT_TIMED_OUT`, `INSUFFICIENT_FUNDS`, `BAD_REQUEST_PAYMENT_DECLINED`, `OTP_TIMEOUT`, `EXPIRED_CARD`, `GATEWAY_ERROR`, `REPEATED_FAILURE`, `SUSPECTED_FRAUD`, `CUSTOMER_ABANDONMENT`)
- `customer_type`: `NEW`, `RETURNING`, `VIP`, or `RISKY`
- `previous_success_count`: Count of past successful payments
- `previous_failure_count`: Count of past failed payments
- `retry_count`: Previous retry attempts
- `time_since_failure_minutes`: Minutes elapsed since initial failure
- `customer_value`: Calculated historical customer value
- `ground_truth_category`: `RECOVERABLE`, `NON_RECOVERABLE`, or `REQUIRES_HUMAN_REVIEW`
- `ground_truth_action`: Target optimal action (`RETRY`, `RECOVERY_LINK`, `REMINDER`, `ESCALATE`, `STOP`)
- `ground_truth_recovery_probability`: Base probability of recovery (0.0 to 1.0)

---

## 3. Ground-Truth Ruleset
Ground-truth expectations are assigned using explicit, explainable domain rules:
1. **High Value / Suspicious Fraud** (`SUSPECTED_FRAUD` or amount > ₹50,000) $\rightarrow$ `REQUIRES_HUMAN_REVIEW` (`ESCALATE`, prob = 0.10)
2. **Exceeded Retry Limits** (`retry_count` $\ge 3$) $\rightarrow$ `NON_RECOVERABLE` (`STOP`, prob = 0.05)
3. **Temporary Network / Gateway Timeout** $\rightarrow$ `RECOVERABLE` (`RETRY`, prob = 0.70 to 0.85)
4. **Expired Card / Auth Failure** $\rightarrow$ `RECOVERABLE` (`RECOVERY_LINK`, prob = 0.65 to 0.80)
5. **Insufficient Funds** $\rightarrow$ `RECOVERABLE` (`REMINDER`, prob = 0.40 to 0.60)
6. **Card Declined without History** $\rightarrow$ `NON_RECOVERABLE` (`STOP`, prob = 0.15)

---

## 4. Decision Pipeline & Policy Constraints
Each synthetic case is evaluated through:
1. **Revenue Risk Engine**: Computes risk score (0–100) and risk level (`LOW`, `MEDIUM`, `HIGH`, `CRITICAL`).
2. **AI Failure Diagnosis**: Recommends action and root cause.
3. **Deterministic Policy Safety Gate**: Enforces hard safety limits (cooldown hours, max retry count $\le 3$, max auto recovery amount $\le$ ₹50,000, minimum confidence $\ge 0.70$).
4. **Outcome Simulation**: Simulates recovery success based on seed-controlled random sampling against `ground_truth_recovery_probability`.

---

## 5. Metric Formulas
- **Precision**: $\frac{\text{Correct Recoverable Predictions}}{\text{All Predicted Recoverable Cases}} \times 100\%$
- **Recall**: $\frac{\text{Correct Recoverable Predictions}}{\text{All Ground-Truth Recoverable Cases}} \times 100\%$
- **Recovery Rate**: $\frac{\text{Successful Recoveries}}{\text{All Recoverable Cases}} \times 100\%$
- **Intervention Rate**: $\frac{\text{Cases with Action } \ne \text{ STOP}}{\text{Total Cases}} \times 100\%$
- **Safe Stop Rate**: $\frac{\text{Correct STOP Decisions}}{\text{All STOP Decisions}} \times 100\%$
- **Unsafe Action Count**: Number of policy-violating interventions (Target: **0**).

---

## 6. CLI Runner & Reproducibility
To run evaluation locally from terminal:
```bash
python scripts/run_evaluation.py --size 1000 --seed 42
```
Outputs complete metric summaries and verifies zero unsafe actions.
